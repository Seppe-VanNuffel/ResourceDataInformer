# Resource Data Informer

## Overview

This mod adds clear production-versus-usage feedback directly to the resource counters in the Infobar.

## Features

- Green arrow when production is comfortably above usage
- Yellow arrow when production is slightly above usage
- Red arrow when production is only barely above usage
- Red downward arrow when usage exceeds production
- Deeper red as the deficit grows
- Includes estimated maintenance in the usage calculation
- Fuel also accounts for rocket refueling
- Electricity, Water, and Oxygen are left unchanged
- Optional on-screen threshold notifications for selected resources

[h2]What this mod adds[/h2]
[list]
[*] [b]Color-coded production arrows[/b] next to resource values in the Infobar.
[*] [b]Green ^[/b] means production is comfortably above usage.
[*] [b]Yellow ^[/b] means production is slightly above usage.
[*] [b]Red ^[/b] means production is only barely above usage.
[*] [b]Red v[/b] means usage exceeds production, with darker red as the deficit grows.
[*] [b]Estimated maintenance[/b] is included in the total usage calculation.
[*] [b]Fuel[/b] also accounts for rocket refueling.
[*] [b]Electricity, Water, and Oxygen[/b] are left unchanged.
[/list]

[h2]Threshold notifications[/h2]
[list]
[*] Configure [b]over[/b] and [b]under[/b] thresholds for each resource.
[*] Receive on-screen alerts when reserves hit or drop below your target.
[*] Works for Metals, Concrete, Food, Polymers, Machine Parts, Electronics, Rare Metals, and Fuel.
[/list]

[h2]Compatibility[/h2]
Designed for [b]Surviving Mars: Relaunched[/b].

The arrows and alerts use the game's Resource Overview statistics for recent production, consumption, and estimated maintenance values.
